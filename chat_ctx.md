Based on the provided context, here is what it says about Bayesian statistics:

*   **Advocacy for New Statistics:** The text advocates using a *Bayesian approach* specifically for doing "New Statistics." While classic tools like maximum likelihood estimation or bootstrapping can still be used to estimate parameters and certainty intervals, the Bayesian approach offers advantages that make it a perfect match for this new statistical framework.
*   **Interpretation of Parameters:** Unlike approaches requiring one to imagine infinite series of replication (a frequentist concept), the Bayesian school requires no such imagination. It provides a *straight-forward interpretation*: there is a best guess for the true value and an interval within which it lies with a given certainty. Bayesian models produce posterior distributions that contain full information on uncertainty, allowing researchers to create certainty statements precisely matching whatever is at stake.
*   **Mathematical Mechanism:** Bayes' formula is described as a law following directly from probability theory (often illustrated using frequencies). It functions as a knowledge processing device or "update" mechanism: it takes *prior knowledge* $P(\theta)$ and the *likelihood* $P(\text{Data}|\theta)$ to calculate the *posterior distribution*. This output represents updated minds/knowledge based on new data.
*   **Certainty Levels:** Bayesian statistics express levels of certainty as a proposition about one's state of knowledge rather than via relative frequencies (e.g., confidence intervals). The text defines this using "credibility intervals," stating that with 95% probability, the true value is contained within the interval. This approach allows for remarkably intuitive statements on uncertainty.
*   **Tools and Applications:** It has developed powerful toolsets like *model selection*, which can be used to test hypotheses or harness the variety of models that can be built. It allows answering Yes/No questions regarding whether an effect contributes to predictions.
*   **Nature vs. Subjectivity Criticism:** While often criticized as subjective because there seems to be no external criterion (like a series of experiments) for certainty, the text suggests it is quite easy to grasp this certainty as an objective quantity when assuming rational decisions and that something at stake exists for the researcher. It equates uncertainty with probability directly in these scenarios without needing detours via relative frequencies or long-running imagined experiments.

**1. Interpretation of Parameters and Uncertainty**

**2. Scope of Uncertainty Information**  
Unlike classic models that only provide uncertainty for a subset of parameters called "population-level coefficients" or population-level terms, Bayesian statistics provides *uncertainty information for every parameter* in the model. This allows practitioners to compare variance parameters between groups or individuals within a group (random effects) and even correlations between individual traits (Source: index.html).

**3. Philosophical View of Data and Parameters**  
Bayesians typically feel that data is "the real thing," whereas a single parameter $\theta$ represents the *current state of knowledge* rather than one absolute true value where randomness is caused by sample fluctuations. In contrast, frequentist statistics assumes there is one true value (Source: ebs.html).

**4. Knowledge Updating Mechanism**  
Bayes' formula is described as an effective device for processing knowledge or updating beliefs by combining existing information with new data inputs. It works as follows (Source: ebs.html):
*   **Prior:** Existing knowledge $P(\theta)$; the state before observation.
*   **Likelihood:** The probability of the data given $\theta$ ($P(\text{Data}|\theta)$).  
*   **Posterior:** Knowledge output after combining prior and data inputs, represented as updated beliefs in science [3.4.6].

**5. Advantages for "New Statistics"**
The text advocates that Bayesian statistics is a *perfect match for New Statistics*. The approach does not require imagining infinite series of replication because the level of certainty or belief can be directly expressed without relative frequencies (Source: index.html). **6. Mathematical Nature**  
Bayesian certainty is described as a probability in mathematical terms that does not require implementation as a relative frequency; it liberates reasoning from the requirement to think of long-running series (Source: ebs.html).
